07 / Coverage

What V1 checks. And what it doesn't.

A focused first release: one cloud, one IaC workflow, the changes that matter most.

What V1 checks

  • Security misconfigurations
  • Permission changes
  • Internet exposure
  • Network changes
  • Resource access changes
  • Security posture changes, before versus after

Technology scope

  • Terraform, and OpenTofu where compatibility can be verified
  • AWS as the first cloud provider
  • GitHub pull requests and GitHub Actions
TerraformAWSGitHub

Not in V1

  • Kubernetes, Azure, GCP
  • A SaaS dashboard
  • Slack or other communication integrations
  • Automated remediation or any automatic infrastructure change
  • Blocking deployments by default

Known gaps

Not evaluated in V1 — a missing finding here does not mean safe. These are recorded as unsupported or analysis-incomplete.

  • IPv6 ::/0
  • Standalone aws_vpc_security_group_ingress_rule
  • Security-group references and prefix lists
  • Unknown values
